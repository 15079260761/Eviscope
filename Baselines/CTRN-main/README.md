# CTRN

## EviScope Table-2 adaptation

The repository-local EviScope entry points are `prepare_eviscope.py` and the
extended `train.py`. The two-GPU experiment is orchestrated by
`../experiments/table2_cronquestions/prepare_table2_inputs.sh` and
`run_table2_method.sh`; the paired protocol, leakage controls and output
contract are documented in that experiment folder.
