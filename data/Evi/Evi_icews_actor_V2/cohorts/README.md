# V2 evaluation cohorts

- `clean_all`: every anchor-valid released question.
- `substitute_effect`: questions eligible for clean and substitute-only views.
- `distractor_effect`: questions eligible for clean and distractor-only views.
- `four_way_common`: the frozen V1 paired cohort eligible for all four views.

Controlled four-condition experiments must continue to use `four_way_common`.
